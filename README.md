# 云阳县民德小学课后服务报名系统

课后服务兴趣社团分班填报系统，部署于 Railway。

## 功能
- 前端：各班级账号登录，班主任为班级学生选报社团
  - 精品社团：全校共用（不分年级）
  - 普通社团：每个年级各有
  - 一个学生只能报一个社团；满 30 人截止；不足 15 人可先报由管理员决定
- 后台：管理员创建社团/批量创建班级账号、审核报名、导出 CSV

## 部署
Railway 自动构建（Nixpacks + gunicorn）。数据存于 `/data`（需挂载卷）。

> ⚠️ 持久化要求（重要）：
> 1. 必须创建数据卷并挂载到服务路径 `/data`（本项目中卷名为 after-school-data）
> 2. 必须设置环境变量 `DATA_DIR=/data`，数据库才会写到卷而不是代码目录
> 3. 两者都配置后，重新部署数据才会保留；否则每次部署数据丢失
