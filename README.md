# 云阳县民德小学课后服务报名系统

课后服务兴趣社团分班填报系统，部署于 Railway。

## 功能
- 前端：各班级账号登录，班主任为班级学生选报社团
  - 精品社团：全校共用（不分年级）
  - 普通社团：每个年级各有
  - 一个学生只能报一个社团；满 30 人截止；不足 15 人可先报由管理员决定
- 教师选课（功能一）：
  - 教师在后台创建教师账号（可填擅长学科）
  - 教师登录后自主选择擅长的社团任教，系统按擅长学科智能推荐匹配课程
  - 教师可查看自己任教学科/社团的：学生名单（含班级、年级、审核状态）、上课地点、上课时间
- 巡课记录（功能二）：
  - 在后台创建巡课人员账号
  - 巡课人员登录后按日期查看当天上课安排（哪一天·哪些人·在哪里上课：社团、授课教师、地点、时间、学生数）
  - 巡课人员对每个社团进行星级评分（1-5 星）与文字评价反馈，同日同社团可更新
  - 管理员在后台查看全部巡课记录（按日期筛选），支持导出 CSV
- 后台：
  - 社团管理：手动创建 / CSV 批量导入社团（含授课教师、上课地点、上课时间）
  - 班级账号：文本批量创建 / CSV 导入（含任课教师、地点、时间）
  - 教师账号：单个 / 批量创建教师账号（含擅长学科），查看其任教社团
  - 巡课人员账号：创建 / 删除巡课登录账号
  - 全校学生管理：CSV 一次性导入全校学生名单（按班级分组，自动归档到各班）
  - 审核报名、导出 CSV、巡课记录导出 CSV

## CSV 导入格式
- 社团：`社团名称,类型,所属年级,授课教师,上课地点,上课时间,人数上限,简介`
  - 类型：`普通` 或 `精品`；精品社团年级留空；人数上限 15-30，缺省 30
- 班级：`班级名,年级,任课教师,上课地点,上课时间`
- 全校学生：`班级,学生姓名`（班级名需与班级账号一致；可一行多姓名 `班级,姓名1,姓名2,...`）
- 均支持 UTF-8 / GBK 编码；后台均有「下载模板」按钮

## 部署
Railway 自动构建（Nixpacks + gunicorn）。数据存于 `/data`（需挂载卷）。

> ⚠️ 持久化要求（重要）：
> 1. 必须创建数据卷并挂载到服务路径 `/data`（本项目中卷名为 after-school-data）
> 2. 必须设置环境变量 `DATA_DIR=/data`，数据库才会写到卷而不是代码目录
> 3. 两者都配置后，重新部署数据才会保留；否则每次部署数据丢失

- 后台批量创建；账号格式 bj+数字，默认密码 123456

## 教师账号（功能一）
- 后台「教师账号」页创建；可填擅长学科（如"语文,书法"）用于选课推荐
- 登录后自主选择任教社团；可查看自己任教社团的学生名单、上课地点、上课时间

## 巡课账号（功能二）
- 后台「教师账号」页 → 「管理巡课人员账号」创建；登录后按日期巡课并评价反馈
- 巡课记录在后台「巡课记录」页统一查看，可导出 CSV
